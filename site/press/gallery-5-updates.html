Updates

Updates itself, and checks the signature twice.

On Linux and Windows, an update installs only if it was signed with the DevsPro release key.

01

Check

Reads the release feed. You see the notes before anything downloads.

02

Download, verify

Fetches the .deb, .rpm or Windows installer and checks its minisign signature.

03

Verify again, elevated

The helper checks it against a key compiled into it, refuses downgrades, then installs.

04

Restart

DevsPro restarts on the new version, as you, with everything where you left it.

One prompt: password or UAC Release notes first Downgrades refused
